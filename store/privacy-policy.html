Back to arXiv

Privacy Policy

Effective date: October 30, 2026 · Extension version 0.4.0

Back to arXiv helps you open or copy arXiv paper links from supported alphaXiv or arXiv pages and hyperlinks. This policy explains the information used by those features.

Information used by the extension

  • Current page URLs, selected link URLs, and paper identifiers. On alphaXiv, the extension reads the page URL to identify a paper and display its controls. When you invoke the toolbar popup or shortcut, it reads the active tab URL to identify a supported paper. When you select Open in arXiv from a paper link's context menu, it reads that link's target URL. These URLs and identifiers are processed in runtime memory for the action you requested.
  • Preferences. Your reading format, current or latest version preference, choice of current or new tab, and interface language are saved in chrome.storage.local in your browser profile. When Follow browser is selected, the extension reads Chrome's interface language to choose a bundled translation.
  • Generated links. The main Copy button writes the paper's arXiv abstract-page link to your clipboard. Its adjacent menu can write an Abstract, PDF, or HTML link. Each link uses your selected current or latest version preference. The extension's clipboard operation is a write of the requested link.

The extension does not read paper text, account details, cookies, form contents, or existing clipboard contents. It does not create a stored browsing-history log.

Purpose and processing

URL processing identifies the requested paper and constructs its arXiv link using your version choice. Current version retains an explicit version suffix; Latest version generates an unversioned URL for arXiv to resolve. Preferences determine the format, version, tab behavior, and interface language. This processing occurs in your browser. The extension contains no analytics, advertising, or developer-operated data collection service.

Navigation to other websites

When you choose an opening action through the page controls, popup, shortcut, or link context menu, your browser sends an HTTPS request to arxiv.org for the selected paper. That request includes the paper path and ordinary browser connection information, such as the IP address and request headers. The destination website handles that visit under its own privacy practices. Browsing alphaXiv is likewise subject to that website's practices.

Retention and your controls

Current page URLs, selected link URLs, and paper identifiers are used transiently while the relevant extension context is running. Saved preferences remain in the browser's extension storage until you change them, clear that storage, or remove the extension. You can change these preferences in the popup. Removing the extension clears its local extension storage.

A copied link follows your operating system's clipboard behavior. You can replace the clipboard contents by copying other text. The extension does not manage your browser history or operating system clipboard history.

Limited Use

Back to arXiv uses information received through Chrome APIs only to provide its stated paper-navigation and link-copying features. This use complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. User data is not sold, used for advertising, or used to determine creditworthiness or lending eligibility.

Updates and contact

This page will be updated when the extension's data practices change. For questions about this policy, contact the maintainer through Back to arXiv's GitHub Issues. Issues are public, so keep questions limited to the policy and the extension's behavior. For private inquiries, use the developer contact information on the Chrome Web Store listing when available.

简体中文说明

隐私政策

生效日期：2026 年 10 月 30 日 · 扩展版本 0.4.0

Back to arXiv 帮助你从受支持的 alphaXiv、arXiv 论文页面或链接打开与复制 arXiv 原文地址。

扩展处理的信息

扩展在 alphaXiv 页面读取当前网址，以识别论文并显示操作按钮。调用工具栏面板或快捷键时，扩展读取当前标签页网址；在论文链接上选择“在 arXiv 中打开”右键操作时，扩展读取该链接的目标网址。这些地址及提取的论文编号在运行时内存中用于完成请求的操作。阅读格式、当前或最新版本偏好、标签页打开方式和界面语言通过 chrome.storage.local 保存在本地浏览器中。选择“跟随浏览器”时，扩展读取 Chrome 的界面语言来选择内置翻译。主复制按钮将生成的摘要页链接写入剪贴板；旁边的菜单可写入摘要、PDF 或 HTML 链接，均采用所选版本偏好。

扩展不读取论文正文、账户信息、Cookie、表单内容或剪贴板已有内容，也不保存浏览历史记录。扩展没有分析统计、广告或开发者运营的数据收集服务。

处理目的

扩展在本地识别论文并生成 arXiv 地址。当前版本保留明确的版本号；最新版本生成省略版本号的链接，由 arXiv 提供最新版本。阅读格式、版本和打开方式决定目标链接与标签页行为，语言偏好决定界面文案。

访问第三方网站

通过页面控件、面板、快捷键或链接右键菜单打开论文时，浏览器通过 HTTPS 请求 arxiv.org 的目标论文页面。该请求包含论文路径，以及 IP 地址、请求头等常规连接信息。arXiv 和 alphaXiv 分别按照各自的隐私规则处理网站访问。

保存期限与控制

当前页面网址、主动选择的链接目标网址及论文编号在相关扩展上下文运行期间临时使用。偏好保存在扩展的本地存储中，可在面板修改；清除扩展存储或移除扩展会删除这些偏好。复制的链接遵循操作系统的剪贴板机制，可通过复制其他内容替换。浏览器历史记录和系统剪贴板历史由相应软件管理。

有限使用与联系

通过 Chrome API 获得的信息仅用于已声明的论文跳转和链接复制功能，遵守 Chrome Web Store 用户数据政策及其 Limited Use 要求。用户数据不用于销售、广告、信用评估或贷款资格判断。数据处理方式变化时，本政策会相应更新。如对政策有疑问，可通过 Back to arXiv 的 GitHub Issues 联系维护者。Issues 内容公开可见，请将问题限定为政策及扩展行为说明。需要私下联系时，可在商店页面提供开发者联系方式后使用该渠道。

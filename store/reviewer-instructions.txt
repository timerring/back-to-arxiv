Back to arXiv 0.4.0 — reviewer test instructions

Access and purpose
The extension opens and copies arXiv paper links from supported alphaXiv/arXiv pages and hyperlinks. Testing uses public paper pages and requires Chrome 120 or later.

1. Initial state
Install and pin Back to arXiv. Open or refresh:
https://www.alphaxiv.org/abs/1706.03762v7
Expected: Open arXiv, Copy, and a copy-format menu at the lower right. Fresh defaults: English, Abstract, Current version, Open in a new tab off.

2. Default navigation
Click the page's Open arXiv control.
Expected current-tab destination: https://arxiv.org/abs/1706.03762v7
Return to the alphaXiv test URL. The popup and shortcut use the same saved reading preferences as the page button.

3. Main Copy action
Click Copy on the page and Copy original link in the popup; paste each result into a local text field.
Expected: https://arxiv.org/abs/1706.03762v7
The main Copy action uses the abstract-page format even when the reading format is PDF or HTML.

4. Copy-format menus
Open the arrow beside Copy in the popup and choose Copy PDF link.
Expected: https://arxiv.org/pdf/1706.03762v7
Choose Copy HTML link (experimental).
Expected: https://arxiv.org/html/1706.03762v7
Repeat using the page's copy menu, including Copy abstract link. The saved reading format stays unchanged. Escape or clicking outside closes an open menu; the actions are also keyboard-accessible.

5. Current and latest versions
In the popup, select PDF and Latest version. The preview becomes arxiv.org/pdf/1706.03762. Open the paper; the destination URL omits v7. Return to the source and copy using each format: the abstract/PDF/HTML URLs also omit v7. Select Current version again; opening and copying retain v7. Latest version creates an unversioned URL locally, which arXiv resolves to its latest paper version.

6. Right-click links on another webpage
Open the public repository README:
https://github.com/timerring/back-to-arxiv
Under Supported URLs, right-click the alphaXiv paper, version 7 test link and choose Open in arXiv. With PDF and Current version selected, expect a new tab at https://arxiv.org/pdf/1706.03762v7 while the GitHub page stays open. Repeat with the arXiv paper, version 7 link. Change the popup to Latest version, then repeat: the new tab uses https://arxiv.org/pdf/1706.03762. Link actions always use a new tab, including when Open in a new tab is off for page/popup/shortcut actions. Restore Current version.

7. Experimental HTML and tab preference
Return to the alphaXiv paper, select HTML (experimental), and enable Open in a new tab. Click Open arXiv in the popup.
Expected new-tab destination: https://arxiv.org/html/1706.03762v7
The source stays open. Reopen the popup: preferences persist. arXiv supplies HTML content; availability depends on the paper and version. Abstract and PDF are alternative reading choices.

8. Shared shortcut
On the source tab, press Alt+Shift+A on Windows/Linux or Option+Shift+A on macOS.
Expected: the paper opens using the saved format, version, and tab preference. The popup displays Chrome's assigned shortcut; use Edit or chrome://extensions/shortcuts to resolve a conflicting assignment.

9. Language and persistence
Select 简体中文. The popup, existing page controls, copy menus, and right-click action use Chinese. Reopen the popup: preferences persist. Select English to restore English. Follow browser uses Simplified Chinese for supported Simplified Chinese locales and English otherwise. A fresh install starts in English even on a Chinese browser.

10. URL cleanup and source scope
With Current version selected, copy from https://www.alphaxiv.org/abs/1706.03762v7?utm_source=test#discussion.
Expected main Copy result: https://arxiv.org/abs/1706.03762v7
On https://www.alphaxiv.org/abs/1706.03762, the result is https://arxiv.org/abs/1706.03762. Page controls are hidden on the alphaXiv home page. On https://example.org the popup waits for a paper and offers preferences. Supported paper links on other webpages still provide the context-menu action.

11. Finish
Restore English, Abstract, Current version, and current-tab opening if desired. Refresh existing alphaXiv tabs after reloading or updating the extension. Updating an older installation retains its reading, tab, and language settings and adds Current version as the default version preference.

Implementation notes
chrome.storage.local saves preferences. content_scripts.matches scopes page controls to the two alphaXiv HTTPS hosts. activeTab supplies the current URL for toolbar/shortcut actions. clipboardWrite writes a requested generated link. contextMenus supplies the explicitly chosen paper link's target URL. URLs and paper identifiers are processed locally in runtime memory; opening a paper performs ordinary HTTPS navigation to arxiv.org. Executable resources are bundled with the package.
